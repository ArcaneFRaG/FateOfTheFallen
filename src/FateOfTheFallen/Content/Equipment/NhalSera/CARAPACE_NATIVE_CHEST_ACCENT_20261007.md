# Carapace Native Chest Accent Pass

The seven-colour debug build established the useful native Eventide mapping:

- Primary (red in debug): chest V/chevron region and waist band.
- Secondary (green): smaller accent regions.
- Leather Primary (blue): thin belt/trim band.
- Metal Primary (magenta): main torso shell and shoulder spikes.
- Metal Secondary (cyan): broad pauldrons.

This means the chest CAN be treated the same way as the shoulders without
adding floating geometry.

Final strategy in this pass:
- Primary: bright/HDR Void purple -> native chest accent.
- Secondary: medium purple -> small native accent details.
- Leather Primary: subtle purple -> thin trim.
- Metal Primary: near-black -> main chest shell + spikes.
- Metal Secondary: dark gunmetal -> broad pauldrons.
- Metal Dark: near-black.

The custom Eventide overlay remains disabled.
