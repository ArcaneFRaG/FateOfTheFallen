# Carapace Hybrid Refinement

User feedback after the native-slot pass:
- shoulders are too bright;
- chestpiece has no accents;
- shoulder glow should be a thin outer edge line, not a solid shoulder fill.

This refinement keeps the native Eventide recolour but tones its broad secondary
channels down to a normal purple. Then it reintroduces a very small overlay only
for the missing mockup detail:
- four chest triangles/shards;
- two thin outer shoulder edge lines.

The overlay is kept almost flush to the Eventide surface so it should no longer
look like it floats in front of the character.
